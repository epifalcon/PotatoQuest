# Potato Quest

Potato Quest is a 2D platformer built in Godot. Four levels: collect potatoes, avoid hazards, and face the Potato King in a final boss battle.

## Features

- Platforming with double jumps, wall jumps, and dashing
- Collectible potatoes that track progress and provide boss-battle ammo
- Hazards, health, falling respawns, and level timers
- A dedicated final boss encounter
- Keyboard and gamepad support

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | Arrow keys or A/D | Left stick or D-pad |
| Jump / select | Space, Enter, or Up/W | Action button |
| Dash | Shift | Right shoulder |
| Shoot potato | E | Right trigger |

## Running the Game

Open the project in Godot 4.6 or newer and press **F5**, or run the included `Platformer Godot.exe` build on Windows.
